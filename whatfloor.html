개인정보 처리방침

앱 이름: 몇층이지 (whatfloor)

시행일자: 2026년 10월 12일 · 최종 수정일자: 2026년 10월 12일

“몇층이지”(이하 “본 앱”)은 사용자의 개인정보를 소중히 다루며, 「개인정보 보호법」 및 「위치정보의 보호 및 이용 등에 관한 법률」을 준수합니다. 본 처리방침은 본 앱이 어떤 정보를 어떤 목적으로 수집·이용하는지 투명하게 설명합니다.

1. 한눈에 보기

어디서무엇어떻게
사용자 기기 안 주차 위치, 층수 등 모든 개별 주차 기록 디바이스 내부 SQLite에 저장. 서버에 보관되지 않음.
사용자 기기 안 → Firebase (옵트인 시) 건물별 학습 결과만 (기준 고도, 평균 층고, 기여 횟수) 익명 처리. 개별 주차 기록·정확한 GPS·개별 주차 시각은 업로드 안 함(최종 갱신 날짜만 일 단위로 저장). 옵트인 OFF가 기본값.
외부 서비스 호출 좌표 → 주소 변환 (Kakao Local API) 좌표만 전송, 사용자 식별자 미포함

핵심: 우리는 누가 언제 어디에 주차했는지 모릅니다.

항목출처사용 목적

2.2 사용자가 직접 입력하는 정보

  • 차량 블루투스 등록 정보 (기기명, 디바이스 ID — 기기 안에만 저장)
  • 층수 (사용자가 직접 확정)

2.3 수집하지 않는 정보

  • 이름, 생년월일, 연락처, 이메일 등 개인 식별 정보
  • 다른 앱 사용 내역
  • 광고 식별자 (IDFA / GAID)
  • 카메라, 마이크, 연락처, 사진 라이브러리

3. 정보의 저장 위치

3.1 로컬 저장 (사용자 기기 안)

다음은 사용자 기기를 떠나지 않습니다:

  • 모든 개별 주차 기록 (시각, 좌표, 층수, 건물명)
  • 차량 블루투스 등록 정보
  • 앱 설정

저장 매체: 디바이스 내부 SQLite 데이터베이스 (앱 샌드박스 내).

3.2 클라우드 저장 (옵트인 시에만)

사용자가 명시적으로 동의(“익명 클라우드 공유”를 ON으로 설정)한 경우에만:

  • 업로드 대상: 건물별 학습 결과
    • 건물명 (도로명 또는 라벨)
    • 좌표 (geohash precision 7, 약 150m 단위로 라운딩 — 정확한 위치 미특정)
    • 학습된 기준 고도, 평균 층고, 기여 횟수
    • 최종 갱신 날짜 (일 단위, 시·분·초 없음)
  • 업로드 안 함: 개별 주차 기록, 정확한 GPS, 정확한 시각, 사용자 식별자

저장 위치: Google Firebase (Firestore, asia-northeast3 = 서울 리전).

기본값은 OFF. 첫 실행 시 동의 시트가 표시되며 사용자가 직접 선택합니다.

3.3 외부 API 호출 (실시간, 저장 X)

  • Kakao Local API: 좌표 → 주소 변환 시 좌표만 전송. 사용자 식별자 미포함.
  • Google Geocoding API: 해외 좌표 대응용 (보조).

4. 이용 목적

  1. 주차 위치 자동 기록: BT 끊김 감지 → 위치 + 시각 저장
  2. 층수 자동 추정: 같은 건물 학습 데이터 + 기압 변화 기반 추천
  3. 알림 제공: 주차 감지 알림 (설정에서 끄기 가능)
  4. 위젯 표시: 홈/잠금화면 위젯에 현재 주차 정보 표시
  5. 클라우드 공유 (옵트인): 다른 사용자가 처음 가는 건물에서도 추천받을 수 있도록 익명 학습 결과 기여

위 외 목적(광고, 분석, 제3자 제공)으로 사용하지 않습니다.

5. 위치 정보 처리 (위치정보보호법 준수)

  • 수집 항목: 위도, 경도, 고도, 정확도, 측정 시각
  • 수집 방법: OS 표준 GPS API
  • 이용 목적: 주차 위치 기록 및 건물 매칭
  • 보관 기간: 사용자가 삭제할 때까지 (앱 내 “전체 기록 삭제”로 즉시 삭제 가능)
  • 백그라운드 위치 사용: 차에서 내릴 때 BT 끊김 직후 1회. 지속 추적 안 함.

저장된 주차 기록은 서버에 보관되지 않습니다. 단, 주소 변환을 위해 좌표가 Kakao Local API로 실시간 전송되며(별도 보관하지 않음), 클라우드 옵트인 시에도 정확한 GPS는 업로드되지 않고 geohash 약 150m 라운딩만 적용됩니다.

6. 사용자 권리

권리행사 방법
열람설정 → 데이터 → 전체 주차 기록
삭제 (개별)전체 기록 화면에서 좌측으로 스와이프
삭제 (전체)설정 → 데이터 → 전체 기록 삭제
클라우드 공유 철회설정 → 익명 클라우드 공유 OFF
권한 철회iOS/Android 시스템 설정에서 위치/알림/블루투스 권한 거부

⚠️ 클라우드 공유의 특성상: 한 번 익명 학습 결과 평균에 반영된 기여는 다른 사용자의 합산 평균과 섞여 개별 분리 삭제가 불가능합니다. 이는 첫 실행 동의 시트에서 명시됩니다.

7. 정보의 제3자 제공

본 앱은 사용자의 정보를 제3자에게 제공하거나 판매하지 않습니다. 다만 다음 경우 예외:

  • 법적 의무: 수사기관의 적법한 영장 등 법적 의무가 있는 경우
  • 위탁 처리 (인프라): 클라우드 옵트인 시 Google Firebase에 건물 학습 결과 저장 (개별 주차 기록 X, 정확한 GPS X)
  • 위탁 처리 (지오코딩): Kakao Local API 호출 (좌표만, 식별자 X)

8. 보안 조치

  • 로컬 데이터: 디바이스 OS의 앱 샌드박스 격리 (iOS Data Protection, Android scoped storage)
  • 네트워크 통신: 모든 외부 API 호출은 HTTPS
  • 클라우드 (Firestore): 익명 인증 토큰 기반 접근 제어, 보안 규칙으로 본인 데이터만 쓰기 가능
  • 분석 도구: 별도 분석/광고 SDK 사용 안 함
